## 자동차 경주 게임 기능 목록

### 주요 기능

- [ ] **자동차 이름 입력**
    - 쉼표(`,`)로 구분하여 여러 이름 입력 가능
    - 각 이름은 1~5자 이내, 중복 불가
    - 공백 자동 제거(trim) 처리
    - 유효하지 않은 입력(`빈 문자열`, `중복`, `5자 초과`) 시 `IllegalArgumentException` 발생

- [ ] **시도 횟수 입력**
    - 1 이상의 정수만 허용
    - 0 이하 또는 숫자가 아닌 값 입력 시 예외 발생

- [ ] **자동차 이동 로직**
    - 각 라운드마다 모든 자동차는 0~9 사이 랜덤값 생성
    - 랜덤값이 4 이상이면 `move()` 호출 → `position` 1 증가
    - 랜덤값이 3 이하이면 이동하지 않음

- [ ] **경주 진행 및 출력**
    - 시도 횟수만큼 반복하며 각 라운드 결과를 출력
    - 자동차 이름과 위치를 `-`로 표시
    - 예시:
      ```
      pobi : --
      woni : -
      jun  : ---
      ```
    - [ ] 모든 라운드 종료 후 최종 우승자 출력
        - 여러 명이 동일 거리일 경우 공동 우승
        - 예: `최종 우승자 : pobi, jun`

- [ ] **예외 처리 및 검증**
    - 자동차 이름 중복 시 예외 발생
    - 이름이 5자 초과 시 예외 발생
    - 시도 횟수가 1 미만일 경우 예외 발생
    - 잘못된 입력 형식 시 프로그램 종료
---

### 테스트 항목

- [ ] **경주 게임 (Car)**
    - `move()` 호출 시 위치가 1 증가하는지 검증
    - 이름이 올바르게 저장되는지 테스트

- [ ] **입력 및 파싱 (InputView / StringParser)**
    - 쉼표 기준으로 이름이 올바르게 분리되는지 검증
    - 이름 중복, 5자 초과 시 예외 발생 테스트
    - 입력 문자열이 공백 또는 빈 값일 때 예외 테스트
    - 시도 횟수가 0 이하이거나 숫자가 아닐 때 예외 발생 테스트

- [ ] **경주 로직 (RacingCarService)**
    - 랜덤값이 4 이상일 때만 이동하는지 검증
    - 랜덤값이 3 이하일 때 이동하지 않는지 검증
    - [ ] 공동 우승자 처리 테스트

- [ ] **출력 (OutputView)**
    - 각 라운드 결과가 `"-"`로 정확히 출력되는지 테스트
    - 최종 우승자 문구가 올바르게 출력되는지 테스트

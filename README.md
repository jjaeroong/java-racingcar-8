## 자동차 경주 게임 기능 목록

## 기능 목록

### **1. 입력 기능**

#### **1-1. 자동차 이름 입력**
- [x] 사용자로부터 자동차 이름 입력받기
- [x] 쉼표(`,`)로 구분하여 여러 이름 입력 가능
- [x] 각 이름의 공백 자동 제거(trim) 처리

#### **1-2. 시도 횟수 입력**
- [x] 사용자로부터 시도 횟수 입력받기
- [x] 문자열을 정수로 변환

---

### **2. 검증 기능**

#### **2-1. 자동차 이름 검증**
- [x] 이름이 1~5자 이내인지 검증
- [x] 빈 문자열이 아닌지 검증
- [x] 중복된 이름이 없는지 검증
- [x] 참가자가 최소 1명 이상인지 검증

#### **2-2. 시도 횟수 검증**
- [x] 시도 횟수가 1 이상의 정수인지 검증
- [x] 숫자 형식이 올바른지 검증

#### **2-3. 위치 검증**
- [x] 자동차 위치가 0 이상인지 검증

---

### **3. 도메인 로직**

#### **3-1. 자동차 이동**
- [x] 0~9 사이 랜덤값 생성
- [x] 랜덤값이 4 이상이면 전진
- [x] 랜덤값이 3 이하이면 정지
- [x] 이동 시 위치값 1 증가

#### **3-2. 자동차 위치 관리**
- [x] 현재 위치 저장
- [x] 위치 1칸 전진 기능
- [x] 위치를 "-" 문자열로 변환

#### **3-3. 자동차 그룹 관리**
- [x] 여러 자동차를 리스트로 관리
- [x] 모든 자동차를 동시에 이동
- [x] 최대 위치를 가진 자동차 찾기
- [x] 공동 우승자 판별 (같은 위치의 자동차들)

---

### **4. 게임 진행**

#### **4-1. 경주 진행**
- [x] 지정된 횟수만큼 라운드 반복
- [x] 각 라운드마다 모든 자동차 이동
- [x] 각 라운드 결과를 리스트에 저장

#### **4-2. 우승자 결정**
- [x] 가장 많이 이동한 자동차 찾기
- [x] 동일 거리의 자동차가 여러 대일 경우 모두 우승자로 판별
- [x] 우승자 이름을 쉼표로 구분하여 문자열 반환

---

### **5. 출력 기능**

#### **5-1. 경주 과정 출력**
- [x] "실행 결과" 메시지 출력
- [x] 각 라운드마다 모든 자동차의 상태 출력
- [x] 자동차 이름과 위치를 "이름 : ---" 형식으로 출력
- [x] 각 라운드 후 빈 줄 출력

#### **5-2. 최종 결과 출력**
- [x] 최종 우승자 이름 출력
- [x] "최종 우승자 : 이름1, 이름2" 형식으로 출력

---

### **6. 예외 처리**

- [x] 자동차 이름이 빈 문자열인 경우 `IllegalArgumentException` 발생
- [x] 자동차 이름이 5자 초과인 경우 `IllegalArgumentException` 발생
- [x] 중복된 이름이 있는 경우 `IllegalArgumentException` 발생
- [x] 참가자가 없는 경우 `IllegalArgumentException` 발생
- [x] 시도 횟수가 1 미만인 경우 `IllegalArgumentException` 발생
- [x] 시도 횟수가 숫자가 아닌 경우 `IllegalArgumentException` 발생
- [x] 위치가 음수인 경우 `IllegalArgumentException` 발생
- [x] 입력값이 null인 경우 `IllegalArgumentException` 발생

---

### 테스트 항목

- [ ] **경주 게임 (Car)**
    - `move()` 호출 시 위치가 1 증가하는지 검증
    - 이름이 올바르게 저장되는지 테스트

- [ ] **입력 및 파싱 (InputView / StringParser)**
    - 쉼표 기준으로 이름이 올바르게 분리되는지 검증
    - 이름 중복, 5자 초과 시 예외 발생 테스트
    - 입력 문자열이 공백 또는 빈 값일 때 예외 테스트
    - 시도 횟수가 0 이하이거나 숫자가 아닐 때 예외 발생 테스트

- [ ] **경주 로직 (RacingCarService)**
    - 랜덤값이 4 이상일 때만 이동하는지 검증
    - 랜덤값이 3 이하일 때 이동하지 않는지 검증
    - [ ] 공동 우승자 처리 테스트

- [ ] **출력 (OutputView)**
    - 각 라운드 결과가 `"-"`로 정확히 출력되는지 테스트
    - 최종 우승자 문구가 올바르게 출력되는지 테스트
